# SeekNow session — 2026-10-08

A logged-in browser is not an API key. The public page loads a Cloudflare Turnstile script and an app bundle that does not name the search route. The known search call remains `POST https://see-know.ru/api/v1/search`.

`SEEKNOW_COOKIE` is sent as a Cookie header when set. `SEEKNOW_API_KEY` is still sent as `X-API-Key` when set. Neither value is stored. If both are empty, gather records `missing_session` and the lookup does not call the site. A 401 body is not a hit. Do not paste the cookie into chat.
