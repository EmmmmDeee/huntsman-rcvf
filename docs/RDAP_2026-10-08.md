# RDAP — 2026-10-08

Keyless domain registration data. `lookup rdap` uses `https://rdap.org/domain/{domain}` and follows the registry redirect. A 404 error object is not a hit. The registrar name is the label. Nameserver names stay in the detail. Gather runs RDAP only when the query contains a dot and no space. SeekNow stays unwired. The HSE monolith is not this crate.
