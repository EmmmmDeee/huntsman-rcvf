# huntsman-recon 0.4.0

Offline case core. No network client. No paid source.

```
huntsman-recon run CASE_DIR
huntsman-recon check
```

`CASE_DIR` may contain `case.json`, `people.json`, `fixes.json`, and `corpus/`. The run writes `out/` and a session bound to the ledger tip. Navigator techniques stay 0.

Identity links on canonical email, handle, or phone. A shared name does not merge. A challenge page is not a hit. SeekNow and public SearXNG are not sources.
